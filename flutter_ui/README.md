# Flutter frontend

Shared visual system, Android settings UI, and public website. Android embeds this module from the root Gradle project so the existing accessibility service and Rust JNI library keep their application ID and stored preferences.

- `flutter pub get`, `flutter analyze`, `flutter test` in this directory.
- Android: run the root Gradle build. `flutter run` in the generated module host does not include the protection service.
- Website: `flutter run -d chrome -t lib/main_web.dart` or `bash scripts/build_web.sh` from the repository root.
- `.android/` and `.ios/` are generated by Flutter and must not be committed or edited.
